권장 안전정책

사용량 기준

외부 연동 설정

Google Calendar / Outlook 직접연동과 SOLAPI 보호자 예약발송을 설정합니다.

Google Calendar

Google Cloud에서 Web application OAuth Client ID를 만든 뒤 입력합니다. Client ID는 비밀키가 아닙니다.
Authorized JavaScript origin


Google Calendar API를 활성화하고 calendar.events, calendar.calendarlist.readonly, calendar.app.created 권한을 사용합니다.

Outlook / Microsoft 365

Microsoft Entra App Registration의 Application (client) ID를 입력합니다. SPA 방식이라 Client Secret은 사용하지 않습니다.
SPA Redirect URI


Delegated permission Calendars.ReadWrite를 추가합니다. 개인 Outlook 계정도 받을 계획이면 앱 등록의 Supported account types도 함께 설정하세요.

OAuth Client ID는 공개 식별자이며 D1에 저장됩니다. Google/Microsoft access token은 CARESTEP Worker/D1에 저장하지 않습니다.
개인정보
병원용 화면의 환자명 포함 옵션은 기본 OFF입니다. ON으로 선택한 경우 환자명은 브라우저에서 연결한 병원 Google/Microsoft 캘린더로 직접 전송되며 CARESTEP 서버에는 저장되지 않습니다.
