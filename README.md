# CARESTEP Clinic v8.4.1 — Daily Workflow Polish

v8.4의 기능을 유지하면서 실제 병원 직원의 일상 사용 흐름을 더 단순하고 안전하게 다듬은 UX 안정화 버전입니다.

## 이번 버전의 6가지 개선

### 1. 홈을 3가지 핵심 행동 중심으로 재구성
홈 최상단에서 바로 다음 세 가지를 선택합니다.
- 새 환자 자료 만들기
- 작성 중인 환자 계속
- 오늘 후속관리 확인

작성 중 케이스가 있으면 환자명, 질환/수술 자료, 현재 작업 단계가 요약되어 표시됩니다.

### 2. 화면별 '다음 할 일'을 명확하게 표시
- 자료실: `이 자료로 만들기 →`
- 자료 생성: `다음: 퇴원지시 →`, `다음: 복약 입력 →`, `다음: 재진 일정 →`, `다음: 출력 확인 →`
- 후속관리: `다음: Journey 확인 →`, `다음: 일정 등록 →`, `다음: 문자 예약 →`, `다음: 최종 확인 →`
- 출력: `병원 기본 패키지 생성 →`

### 3. Smart Reset Guard 통일
작성 중인 환자가 있는 상태에서 홈/상단/자료실/최근 사용 자료 등에서 새 환자를 시작하려 하면 CARESTEP이 먼저 현재 케이스를 보여줍니다.
- `이어서 작성`
- `새 환자로 초기화`

병원정보, 프리셋, 발신번호, 계정 설정은 초기화되지 않습니다.

### 4. 브라우저 새로고침·창 닫기 보호
작성 중인 환자 케이스가 있을 때 새로고침, 탭 닫기, 페이지 이탈을 시도하면 브라우저 기본 경고가 표시됩니다.

환자정보를 서버나 localStorage에 새로 저장하지 않으면서 실수로 입력내용을 잃는 위험을 줄였습니다.

### 5. 출력 단계 단순화
평소에는 현재 병원 기본 출력구성 요약과 `병원 기본 패키지 생성 →` 버튼만 우선 표시합니다.

세부 출력물 선택과 프리셋 변경은 `출력물 상세 설정`을 펼쳤을 때만 보입니다.

### 6. 후속관리 할 일 배지
좌측 `후속관리` 메뉴에 오늘 미완료 업무 + 확인 필요 항목 수를 작은 배지로 표시합니다.

홈의 `오늘 후속관리` 카드에서도 오늘 업무와 확인 필요 건수를 확인할 수 있습니다. SOLAPI 실패/보호자 설문 경고는 로그인 후 백그라운드에서 갱신하며, Google Calendar 일정은 해당 브라우저에서 Google Calendar가 연결된 경우 함께 계산됩니다.

## 유지되는 기존 기능
- v8.3 Smart Case Flow / 자료 생성 → 후속관리 자동 인계
- Education → Patient Journey Auto Sync
- 병원용 Journey 복제·편집·삭제
- Google Calendar / Outlook 직접 연동
- SOLAPI 예약발송 및 예약취소 핫픽스
- 발신번호 온보딩 / HQ 발신번호 관리
- 보호자 설문·만족도
- Follow-up CRM
- SaaS 사용량·과금·병원 운영관리

## 개인정보 원칙
이번 개선으로 환자정보를 서버 저장하는 기능은 추가하지 않았습니다. 환자명, 보호자명, 복약정보, 개별 퇴원지시는 기존처럼 현재 브라우저 탭의 작업 메모리에서만 사용합니다.
