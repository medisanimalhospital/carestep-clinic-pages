# CARESTEP Clinic v8.3 · Smart Case Flow & Auto Reset

v8.3은 자료실 → 자료 생성 → 후속관리 사이에서 이전 환자/질환 입력이 남아 재설정해야 하던 불편을 줄이고, 자료 생성이 끝나면 현재 케이스를 후속관리로 자연스럽게 이어주는 UX 업데이트입니다.

## 1. 자료 생성 → 후속관리 자동 인계

출력물 생성이 성공하면 현재 케이스를 후속관리 화면으로 자동 전달합니다.

유지되는 현재 케이스 정보:
- 선택 교육자료/질환
- 환자명
- 보호자명
- 관리 시작일
- 이름 표시 여부
- 담당 수의사 개별 퇴원지시
- 복약/재진 입력

현재 교육자료와 연결된 Published Patient Journey가 있으면 자동으로 찾아 적용하고, 후속관리 가이드는 환자·Journey 확인을 마친 상태에서 일정 단계로 이어집니다.

출력 단계 하단에는 `현재 정보로 후속관리 계속 →` 버튼도 추가했습니다. 자동 이동을 기다리지 않고 바로 이동할 수 있습니다.

## 2. 교육자료 변경 시 이전 질환 입력 자동 초기화

자료 생성 Step 1에서 다른 교육자료를 선택하면 이전 질환의 내용이 새 질환에 섞이지 않도록 자동 정리합니다.

유지:
- 환자명
- 보호자명
- 관리 시작일
- 이름 표시 여부

자동 초기화:
- 이전 질환의 개별 퇴원지시
- 복약 입력
- 재진 설정
- 적용 Patient Journey
- 현재 후속관리 case nonce
- 보호자 문자 입력/동의 상태
- 직원 인계 체크

## 3. 전역 `+ 새 환자 / 초기화`

병원 화면 상단에 항상 사용할 수 있는 `+ 새 환자 / 초기화` 버튼을 추가했습니다.

초기화 대상:
- 환자정보
- 개별 퇴원지시
- 복약 입력
- 재진 설정
- 적용 Journey
- 후속관리 가이드 진행상태
- 현재 문자 입력/동의

유지 대상:
- 병원정보
- 병원별 퇴원 프리셋
- 출력 기본값
- Google/Outlook 연동
- SOLAPI/발신번호 설정
- 요금제/직원/운영 설정

## 4. 후속관리 완료 후 스마트 초기화

후속관리 Step 5에서 `후속관리 설정 완료`를 누르면 현재 케이스가 완료 상태가 됩니다.

이후 `자료실` 또는 `자료 생성`으로 이동하면 다음 환자를 위한 새 케이스로 자동 초기화합니다.

반대로 후속관리를 아직 완료하지 않은 상태에서 자료 생성 ↔ 후속관리 사이를 오갈 때는 현재 환자정보를 유지합니다. 수정이 필요할 때 데이터가 갑자기 사라지지 않도록 하기 위한 동작입니다.

## 5. 상단 현재 케이스 표시

상단에 현재 상태를 표시합니다.

예:
`후속관리중 · 코코 · 슬개골 수술 후 관리`

상태는 `작성중 → 출력완료 → 후속관리중 → 완료` 순서로 표시됩니다.

## 기존 기능 유지

- Guided Follow-up Workflow
- Patient Journey Auto Sync
- 병원용 Journey 복제/편집/삭제
- 자료실 ↔ Journey 카테고리 동기화
- Google Calendar / Outlook
- SOLAPI 예약발송 및 예약취소
- 발신번호 중앙 관리
- 보호자 설문/만족도
- Follow-up CRM
- 사용량/과금/HQ 운영관리

## 배포

1. Cloudflare Worker를 `worker-paste-ready.txt` 전체 내용으로 교체 후 Deploy
2. 병원용 `index.html` 교체
3. HQ용 `hq.html` 교체
4. 브라우저 `Ctrl+Shift+R`

새 Worker Secret은 없으며 D1 SQL을 직접 실행할 필요도 없습니다.
