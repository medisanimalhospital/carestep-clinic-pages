# CARESTEP Clinic v8.8.1 — Real-time Messaging Delivery Confirmation

## 핵심 변경
- 온보딩 문자 테스트는 기존처럼 **즉시 발송**합니다. D+1 예약발송과 분리되어 있습니다.
- SOLAPI 접수 성공만으로 온보딩을 완료하지 않고, **실제 전달 완료 상태를 자동 확인한 뒤** 문자 단계가 완료됩니다.
- 테스트 발송 후 약 30초 동안 브라우저가 2초 간격으로 전달상태를 자동 확인합니다.
- 확인이 늦어져도 **퇴원자료 생성, Patient Journey, 후속관리 등 CARESTEP 사용은 차단하지 않습니다.**
- 사용자는 `전달상태 확인` 버튼으로 언제든 다시 확인할 수 있습니다.
- 실패가 확인되면 온보딩 문자 단계가 `확인 필요`로 표시되고 재테스트할 수 있습니다.
- HQ 개통센터에서도 `전달 확인 중 / 발송 실패 / 실제 발송 완료` 상태를 구분합니다.

## D1 / Secret / Cron
- 새 Secret: 없음
- 수동 D1 SQL: 없음. Worker가 `clinic_onboarding_state`에 필요한 컬럼을 자동 추가합니다.
- Cron 변경: 없음. 기존 `15 0 * * *` 유지

## 테스트 방법
1. Worker → index.html → hq.html 순서로 배포 후 Ctrl+Shift+R
2. 병원 Owner/Admin → 시작 설정 또는 후속관리 → 병원 발송 연동
3. 테스트 수신번호 입력 → `테스트 1건 즉시 발송`
4. 화면에 `문자 발송 중 · 전달상태 확인 중` 표시 확인
5. 실제 휴대폰 수신 후 `✓ 실제 발송 완료 확인`으로 자동 변경되는지 확인
6. 시작 설정의 문자 단계가 완료되고 Go-Live 진행률이 올라가는지 확인
7. 전달 확인이 30초 이상 걸리면 다른 메뉴 사용이 가능한지 확인한 뒤 `전달상태 확인`으로 재확인

## 개인정보
테스트 수신번호는 SOLAPI 전송에만 사용하며 온보딩 상태에는 전화번호를 저장하지 않습니다. D1에는 SOLAPI group ID, 전달상태, 요청/확인 시각 같은 운영 메타데이터만 저장합니다.
