# CARESTEP Clinic v6.3.2.4 · DYNAMIC MEDICATION CHECKLIST

## 이번 패치
- 고정 `7일 복약 체크표`를 제거했습니다.
- 각 약의 `투약 기간(일수)`을 1~90일 숫자로 입력합니다.
- 체크표 전체 길이는 가장 긴 처방기간에 맞춰 자동 결정됩니다.
- 서로 다른 처방기간을 동시에 반영합니다. 예: A 3일 / B 5일 / C 14일.
- 각 약은 자기 투약 종료일까지 체크박스가 나오고, 이후 날짜는 `—`로 표시됩니다.
- 등록된 투약시간마다 체크박스를 각각 생성합니다. 시간이 없으면 날짜별 `완료 □` 1칸을 표시합니다.
- 퇴원일/관리 시작일을 기준으로 각 일차의 실제 날짜를 함께 표시합니다.
- 1~7일은 1P, 8~14일은 2P, 이후는 7일 단위로 자동 페이지 분할합니다.
- 투약일수가 빠진 약이 있으면 복약 체크표 생성을 막고 입력을 안내합니다.
- 패키지/개별 출력물의 이름과 파일명도 `3일/5일/14일 복약 체크표`처럼 자동 변경됩니다.

## 배포
이번 변경은 프론트엔드 전용입니다.
1. GitHub Pages 루트의 기존 `index.html`을 이 버전으로 교체합니다.
2. Commit changes 합니다.
3. Cloudflare Worker는 현재 사용 중인 v6.3.2.2 코드를 그대로 유지합니다.
4. 배포 후 강력 새로고침(Ctrl+F5)을 권장합니다.

## 예시
- 약 A: 08:00 / 20:00 / 3일
- 약 B: 20:00 / 5일
- 약 C: 08:00 / 20:00 / 14일

결과: 14일 체크표(2P)가 생성되고 A는 3일차, B는 5일차, C는 14일차까지만 체크칸이 표시됩니다.
