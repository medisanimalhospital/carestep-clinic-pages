# CARESTEP Clinic v8.2 · Guided Follow-up Workflow

v8.2는 기능을 더 늘리는 버전이 아니라, 기존 후속관리 기능을 **처음 사용하는 직원도 순서대로 따라갈 수 있는 5단계 가이드**로 재구성한 UX 버전입니다.

## 핵심 변경

### 1. 후속관리 설정을 5단계로 단순화
1. 환자·퇴원자료 확인
2. Patient Journey 적용
3. Google/Outlook 캘린더 등록
4. 보호자 자동발송 예약
5. 최종 확인 및 설정 완료

상단 Stepper가 현재 위치와 완료 여부를 표시합니다. 완료된 단계는 체크 표시, 현재 단계는 파란색, 건너뛴 단계는 별도 상태로 표시됩니다.

### 2. 자료실과 연결된 Journey 추천
현재 선택한 교육자료와 `sourceId`가 연결된 CARESTEP 기본 Journey가 있으면 Step 2에서 **추천 Journey 적용** 버튼을 보여줍니다.

자동 적용하지 않고 수의사/직원이 확인 후 적용하도록 유지합니다.

### 3. 일반 직원 화면과 고급 설정 분리
일반적인 케이스 설정에서는 필요한 행동만 먼저 보여줍니다.

- Journey: `현재 케이스에 적용` 중심
- 복제/편집/삭제/새 Journey: `고급 설정`
- Calendar: 일정 등록 중심
- .ics/TXT/ZIP 및 세부 기본설정: `고급 설정`
- 자동발송: 보호자 번호 → 동의 → 예약 중심
- 발신번호·SOLAPI·카카오 템플릿 설정: `관리자 설정`

기존 기능은 삭제하지 않았습니다.

### 4. Calendar 완료 후 자동으로 다음 단계
Google Calendar 또는 Outlook에 현재 케이스 일정을 정상 등록하면 Step 3이 완료 처리되고 Step 4 보호자 발송으로 이동합니다.

Calendar를 사용하지 않는 병원은 `캘린더 없이 계속`을 선택할 수 있습니다.

### 5. 문자 예약 완료 후 자동으로 최종 확인
SOLAPI 예약발송이 정상 접수되면 Step 4가 완료되고 Step 5로 이동합니다.

문자 자동발송을 사용하지 않는 케이스는 `문자 없이 계속`을 사용할 수 있습니다.

### 6. 최종 확인 화면
설정 완료 전 다음을 한눈에 확인합니다.

- 적용 Patient Journey
- Calendar 등록 건수/상태
- 보호자 문자 예약 건수/상태
- 보호자 설문 예정 단계

`후속관리 설정 완료`를 누르면 운영 대시보드로 전환됩니다.

### 7. 설정 모드 / 운영 모드 분리
**설정 가이드**에서는 케이스 준비만 보여주고, **운영 대시보드**에서는 실제 업무에 필요한 항목을 중심으로 보여줍니다.

운영 화면 상단 KPI:
- 오늘 미완료 업무
- 확인 필요
- 예약/처리중 문자
- 활성 CRM 케이스

기존 Google Calendar 업무보드, 발송 실패, 보호자 설문, Follow-up CRM, 운영분석은 그대로 유지됩니다.

## v8.1.3 기능 유지
- SOLAPI 예약취소 안정화 핫픽스
- Patient Journey 자동동기화
- 자료실/후속관리 카테고리 통일
- 병원 Journey 복제/편집/보관/삭제
- 보호자 설문 및 만족도
- Follow-up CRM 위험도
- 사용량/과금 관리
- 발신번호 온보딩

## 개인정보
v8.2 가이드 진행상태는 현재 브라우저의 `sessionStorage`에 케이스 nonce 기준으로만 보관합니다.

CARESTEP D1에는 기존 원칙대로 보호자 전화번호·메시지 본문을 저장하지 않습니다.

## D1 / Worker Secret
- 새 D1 테이블 없음
- SQL 직접 실행 없음
- 새 Worker Secret 없음

## 배포 순서
1. Cloudflare Worker → `worker-paste-ready.txt` 전체 교체 → Deploy
2. 병원용 `index.html` 교체
3. HQ `hq.html` 교체
4. 브라우저 `Ctrl + Shift + R`
5. 후속관리 화면 상단에 `GUIDED FOLLOW-UP WORKFLOW · v8.2` 확인

## 권장 첫 테스트
1. 자료 생성에서 관리 시작일 입력
2. 후속관리 진입
3. Step 1 완료 상태 확인
4. Step 2에서 추천 Journey 적용
5. Step 3에서 Google Calendar 일정 등록
6. 자동으로 Step 4 이동 확인
7. 테스트 번호로 자동발송 예약
8. 자동으로 Step 5 이동 확인
9. 최종 확인 → `후속관리 설정 완료`
10. 운영 대시보드 전환 확인
