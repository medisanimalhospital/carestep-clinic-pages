# CARESTEP Clinic v6.6.5 · Follow-up Analytics

## 배포
이번 버전은 병원용 `index.html`만 교체합니다.

1. GitHub Pages 저장소 루트의 `index.html`을 이 버전 파일로 교체
2. Commit
3. CARESTEP 병원 페이지에서 Ctrl+F5

`hq.html`, Cloudflare Worker, D1, Secret은 v6.6.4에서 변경할 필요가 없습니다.
Google OAuth Scope도 v6.6.3에서 설정한 범위를 그대로 사용합니다.

## 새 기능
### 후속관리 운영 분석
선택한 Google Calendar의 CARESTEP 후속관리 이벤트를 브라우저에서 집계합니다.

조회 기간:
- 최근 30일
- 최근 90일
- 최근 180일

핵심 지표:
- 대상 업무
- 완료율
- 지난 미완료
- 수의사 확인 발생률
- 재연락 업무 비율
- 평균 완료시간

상세 분석:
- 연락 결과 분포
- D+ 단계별 처리율
- 담당자별 처리현황
- 운영 인사이트

### 집계 CSV
`집계 CSV`를 누르면 환자명·보호자명·일정 제목·처리 메모를 제외한 집계 데이터를 CSV로 다운로드합니다.
포함 데이터는 기간, 업무 수, 완료율, 결과 분포, 단계별 집계, 담당자별 집계입니다.

## 요금제 권한
후속관리 분석은 두 권한을 모두 확인합니다.
- `followupAutomation`
- `pilotAnalytics` (화면 표시명: 운영 분석)

기본 요금제 정책 기준:
- PILOT: 사용 가능
- BASIC: 사용 불가
- PRO: 사용 가능
- ENTERPRISE: 사용 가능

## 개인정보
- 통계 원본은 선택한 Google Calendar에서 브라우저로 직접 읽습니다.
- CARESTEP D1에 환자명, 보호자명, 일정 제목, 처리 메모를 저장하지 않습니다.
- 통계 데이터도 서버에 별도 적재하지 않습니다.
- CSV에는 환자정보를 넣지 않고 집계값과 담당 직원명만 포함합니다.

## 기존 데이터 호환
v6.6.1~v6.6.3에서 만든 일정은 완료/결과/담당자 정보가 없을 수 있으므로 `결과 미입력` 또는 `미배정`으로 집계될 수 있습니다.
v6.6.4 이후 결과 기록을 시작한 일정부터 분석의 정확도가 높아집니다.

## 현재 범위
- Google Calendar 후속관리 전용 캘린더 기준 통계입니다.
- Outlook Calendar 일정 등록 기능은 유지되지만 Outlook 업무 통계는 아직 포함하지 않습니다.
- 한 조회에서 최대 2,500개의 CARESTEP 후속관리 이벤트를 페이지네이션으로 읽습니다.
